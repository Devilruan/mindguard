作品简介（287字 / ≤300字）
=============================

【问题】校园心理中心面临筛查手段单一、漏检率高、缺乏可解释性三大痛点：某高校2025年筛出高风险98人，后续辅导员跟进又发现47人（漏检32%），其中70%在PHQ-9上得分<10，传统纯量表法完全无法识别。

【方案】立足精神医学与人工智能交叉前沿，提出神经符号双引擎驱动的心理风险智能筛查系统。融合PHQ-9/GAD-7临床量表与开放文本语义分析，通过规则知识库（6条DSM-5阈值规则+RIPPER规则归纳）与4级危机分级拦截机制，在PHQ-9显示"正常"时仍能检出自杀倾向隐性信号。RAG心理知识库自动生成个性化干预建议。

【效果】118例样本对比实验表明：本引擎比传统纯量表法额外检出12例（全部为纯量表漏检的文本暴露危机案例），检出率净提升16.3%。每条风险结论附带完整规则激活链确保可解释性。

【应用】纯Python实现、PyInstaller一键打包，可直接部署至任何高校心理中心。

打包命令（生成可执行 exe）
=============================

1. 安装 PyInstaller：pip install pyinstaller
2. 在源码目录下执行：
   pyinstaller --onefile --uvicorn --module fastapi --module sqlalchemy --module pydantic --module python_docx --module jinja2 --name mmhs main.py
3. 生成的 dist/mmhs.exe + 源码目录中的 frontend/ + config/ + .env + mmhs.db 一起打包

或者直接用已有的 PyInstaller 提取目录 mmhs.exe_extracted/（已经包含所有第三方库）
